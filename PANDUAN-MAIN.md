# Panduan Bermain — Arena Mandarin

Panduan untuk **anak, orang tua, dan guru**. Tidak perlu daftar, tidak perlu
internet setelah dibuka sekali. Cukup pilih avatar, tulis nama, main.

---

## Mulai dalam 30 detik

1. Buka alamat aplikasinya (atau file `public/index.html`)
2. **Pilih avatar** — 12 hewan lucu, ketuk salah satu
3. **Tulis nama**, ketuk **Mulai main! 🚀**
4. Pilih game mana pun → jawab soal → kumpulkan ⭐

Nama dan avatar tersimpan otomatis, jadi besok tinggal buka lagi.

---

## Install di HP atau tablet

Setelah aplikasi dibuka lewat HTTPS:

- **Android / Chrome / Edge:** ketuk tombol **Install** di kanan atas, atau buka menu browser lalu pilih **Install aplikasi**.
- **iPhone / iPad:** ketuk tombol **Bagikan**, lalu pilih **Tambahkan ke Layar Utama**.

Setelah terpasang, aplikasi bisa dibuka dari ikon layar utama dan materi yang
sudah pernah dibuka tetap tersedia saat offline.

---

## Mengenal layar beranda

| Bagian | Fungsi |
|---|---|
| **Bar atas** | Logo, tombol tema 🌙/☀️, suara 🔔/🔕, dan total ⭐ |
| **Level** | Tingkat kesulitan — Beginner / Intermediate / Advanced |
| **Fokus belajar** | Saring game per topik. "Semua" menampilkan 18 game |
| **Kartu game** | Ketuk untuk main. Bintang kecil di pojok = rekor terbaikmu |
| **Papan bintang** | Peringkat pemain di perangkat ini |

Tombol **Ganti pemain** untuk bergantian dengan adik/kakak — bintang masing-masing
tersimpan terpisah.

## Bintang & rating

**Setiap jawaban benar = 1 ⭐**, langsung masuk ke total dan papan bintang.

Selesai satu ronde, muncul kartu hasil dengan rating bintang:

| Rating | Syarat |
|---|---|
| ★★★ | Semua benar (100%) — dirayakan **confetti** 🎉 |
| ★★☆ | Benar 70% atau lebih |
| ★☆☆ | Di bawah 70% |

Dua game punya aturan sendiri:

- **Kartu memori** — rating dari jumlah langkah. Makin sedikit langkah, makin
  banyak bintang.
- **Lomba cepat** — rating dari jumlah benar dalam 60 detik (18+ = ★★★, 10+ = ★★☆).

### Beruntun 🔥

Jawab benar **2 kali berturut-turut** → muncul lencana 🔥 di bar atas dan terus
naik. Salah satu kali, hitungannya kembali ke nol.

## Level — pilih yang pas

Level bukan sekadar label; isi soalnya benar-benar berubah:

| | Beginner | Intermediate | Advanced |
|---|---|---|---|
| Pilihan jawaban | **3** | **4** | **5** |
| Kosakata | 1 hanzi (猫, 山) | semua | 2+ hanzi (熊猫, 学校) |
| Angka | 1–10 | 6–50 | 31–100 |
| Panjang kalimat | 2–3 kata | 2–4 kata | 4+ kata |
| Kartu memori | 12 kartu | 12 kartu | 16 kartu |

**Saran:** mulai dari Beginner. Kalau sudah sering ★★★, naik ke Intermediate.

> Satu ronde = **30 soal**. Terlalu panjang untuk anak kecil? Guru/orang tua bisa
> menguranginya lewat panel admin (lihat bagian bawah).

## 18 game

### 🎴 Kosakata

| Game | Cara main | Melatih |
|---|---|---|
| **Tebak kata** | Muncul hanzi → pilih artinya | Mengenali arti kata |
| **Tebak pinyin** | Muncul hanzi → pilih cara bacanya | Cara baca |
| **Arti ke hanzi** | Muncul arti → pilih hanzi yang benar | Mengingat tulisan |
| **Kartu memori** | Buka 2 kartu, pasangkan hanzi dengan artinya | Ingatan |

### 🔊 Dengar & Ucap

| Game | Cara main | Melatih |
|---|---|---|
| **Tebak nada** | Muncul pinyin → pilih nada 1–4 | Nada Mandarin |
| **Dengar & tebak** | Ketuk 🔊, dengarkan, pilih artinya | Menyimak |
| **Ketik pinyin** | Muncul hanzi → **ketik** cara bacanya | Menulis pinyin |

> **Ketik pinyin boleh tanpa tanda nada.** Ketik `ni hao` untuk `nǐ hǎo` — tetap
> dihitung benar. Tekan `Enter` untuk memeriksa.

> **Dengar & tebak** butuh suara Mandarin (zh-CN) di perangkat. Kalau tidak ada,
> kartunya otomatis dinonaktifkan (abu-abu) — bukan rusak.

### 🔢 Angka & Waktu

| Game | Cara main | Melatih |
|---|---|---|
| **Cocokkan angka** | Muncul angka → pilih hanzi-nya | Angka 1–30 |
| **Matematika** | 三 + 二 = ? → pilih jawaban dalam hanzi | Berhitung + angka |
| **Hari & waktu** | Muncul kata Indonesia → pilih Mandarinnya | Hari, bulan, waktu |
| **Jam berapa** | Muncul jam (9:30) → pilih bacaan Mandarinnya | Membaca jam |

### 📏 Tata Bahasa

| Game | Cara main | Melatih |
|---|---|---|
| **Kata ukur** | 一 ___ 猫 → pilih kata ukur yang tepat | Kata ukur |
| **Lawan kata** | Muncul 大 → pilih lawannya (小) | Kata berlawanan |
| **Susun kalimat** | Ketuk kata satu per satu sampai jadi kalimat | Pola kalimat |

> Di **Susun kalimat**, salah ketuk? Tekan **↶ Hapus terakhir**. Tombol 🔊 untuk
> mendengarkan kalimatnya.

### 💬 Percakapan

| Game | Cara main | Melatih |
|---|---|---|
| **Salam sopan** | Muncul situasi → pilih ucapan yang tepat | Sapaan sehari-hari |
| **Lengkapi dialog** | Muncul pertanyaan → pilih jawaban yang cocok | Percakapan |

### 🏆 Tantangan

| Game | Cara main | Melatih |
|---|---|---|
| **Lomba cepat** | Jawab sebanyak mungkin dalam **60 detik** | Kecepatan |

## Untuk orang tua & guru

### Main bergantian

Ketuk **Ganti pemain** → tulis nama baru. Setiap anak punya bintang sendiri, dan
semuanya tampil di papan bintang perangkat itu.

### Atur lewat panel admin

Buka `/admin` (atau tautan **⚙️ Panel Admin** di bawah halaman). PIN awal: `1234`.

Yang bisa diatur:

- **Jumlah soal per game** — 30 terasa panjang untuk anak TK? Turunkan ke 10–15.
- **Matikan game tertentu** — misal sembunyikan "Lomba cepat" agar anak tidak
  terburu-buru.
- **Level & fokus awal** — atur titik mulai untuk pemain baru.
- **Tampilan** — ganti nama, logo, dan warna jadi identitas sekolah Anda.

> ⚠️ PIN admin **bukan pengaman sungguhan** — hanya penghalang ringan agar anak
> tidak asal mengubah setelan. Lihat [README](README.md#dua-peran-pemain--admin).

### Saran pemakaian

- **Anak baru mulai:** Beginner + fokus **Kosakata**, 10–15 soal.
- **Sudah lancar kata:** fokus **Dengar & Ucap** untuk melatih nada — bagian
  tersulit Mandarin bagi penutur Indonesia.
- **Ulangan/evaluasi:** fokus **Tantangan** → Kuis campuran.
- Soal **berulang** di beberapa game (misal angka Beginner cuma 1–10). Ini
  disengaja — pengulangan berjarak membantu hafalan.

## Hal-hal yang perlu diketahui

- **Bisa offline.** Setelah dibuka sekali lewat internet, aplikasi tetap jalan
  tanpa koneksi. Bisa juga di-*install* ke layar utama HP (menu browser →
  "Tambahkan ke layar utama").
- **Data tidak ke mana-mana.** Nama, bintang, dan papan tersimpan **di perangkat
  itu saja**. Tidak dikirim ke server mana pun, tidak ada iklan, tidak ada
  pelacakan.
- **Papan bintang tidak lintas perangkat.** Skor di tablet tidak muncul di HP.
- **Bintang hilang?** Membersihkan data browser akan menghapusnya. Papan juga bisa
  dikosongkan sengaja lewat tombol **Kosongkan**.
- **Animasi mengganggu?** Kalau perangkat menyetel *reduce motion*, semua animasi
  (confetti, semburan bintang) otomatis mati.
